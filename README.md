# K-mer Frequency Analysis Script

This project is a Python-based tool that reads a DNA sequence file and performs analysis on **k-mers**—substrings of length `k`—along with the frequencies of the characters that immediately follow each k-mer. 

---

## What the Script Does

The main script (`python_final.py`) performs the following tasks:

1. Reads a DNA sequence from a fixed `.fa` file:
   ```
   /mnt/homes4celsrs/shared/439539/reads.fa
   ```

2. Takes one command-line argument: an integer `k` (the k-mer length)

3. Outputs a file (`kmer_output.txt`) containing:
   - The total count of each k-mer in the sequence
   - The count of each character that directly follows each k-mer

---

## How to Run the Script

### Requirements:
- Python 3
- The file `/mnt/homes4celsrs/shared/439539/reads.fa` must exist and be readable

### Running the script from the command line:

Use the following syntax:

```bash
python python_final.py <k>
```

Replace `<k>` with any positive integer less than the length of the sequence.

#### Example:
To analyze 3-mers:

```bash
python python_final.py 3
```

### What gets created:

- A file called `kmer_output.txt` will be written to your working directory
- It will contain:
  - A list of k-mers and how often they appear
  - A list of what characters follow each k-mer, and how often

---

## File Output Format

Example output for `k=3`:

```
K-mer Frequencies:
ATG: 2
TGA: 1
GAT: 1

Follower Frequencies:
ATG -> G: 1
TGA -> T: 1
GAT -> A: 1
```

## How to Run the Tests

The test suite is located in `test_python_final.py`. It uses `pytest` to run simple tests on every function in the main script.

### Step-by-step instructions:

1. Make sure `pytest` is installed. If not, you can install it using:

```bash
pip install pytest
```

2. Run the tests from the command line:

```bash
pytest test_python_final.py
```

### What is tested:

- `count_kmers(sequence, k)`: Returns correct counts, handles empty strings and overly large `k`
- `count_followers(sequence, k)`: Accurately counts which characters follow each k-mer
- `read_sequence(path)`: Correctly strips line breaks and concatenates a `.fa` file
- `write_output(kmer_counts, follower_counts, path)`: Creates output with expected content

### What files are created during testing:

- `test_sequence.fa`: Used to simulate input during tests
- `test_output.txt`: Used to test output writing

These files are **not deleted** after testing so you can inspect them.

---

## Function Descriptions

The main script is modular, with clear functions:

- `read_sequence(path)`: Reads and concatenates all lines from a `.fa` file
- `count_kmers(sequence, k)`: Counts all substrings of length `k` in the input sequence
- `count_followers(sequence, k)`: Tracks what character immediately follows each k-mer and how often
- `write_output(kmer_counts, follower_counts, path)`: Outputs results to a text file
- `main()`: Orchestrates the script's execution (reading input, calling other functions)
